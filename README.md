Projet final de la formation Data Fullstack

# Prédiction du retour des utilisateurs

## Description

Ce projet a pour objectif de prédire si un utilisateur
va revenir sur le site à partir de différentes caractéristiques
comportementales.

## Objectifs

- Explorer les données
- Préparer les variables
- Entraîner plusieurs modèles de classification
- Comparer leurs performances
- Optimiser les hyperparamètres avec GridSearchCV
- Interpréter le modèle final

## Modèles utilisés

- Logistic Regression
- Random Forest
- Gradient Boosting
- Decision tree
- XBoost

## Évaluation

Les modèles sont comparés à l'aide de :

- Accuracy
- Precision
- Recall
- F1-score
- Matrice de confusion

## Interprétation

Une analyse de l'importance des variables est réalisée
avec le modèle Gradient Boosting.
